# HTTP Status Code lookup

Type or paste a 3-digit HTTP status code (e.g. `404`, `429`, `503`) in the Bolt launcher. Bolt instantly recognizes the code and offers MDN documentation, visual debug references, and ready-to-copy Markdown links.

## Who it is for

Frontend, backend, and API developers debugging HTTP response codes and network logs.

## What it saves

Eliminates manual searches for HTTP status specifications, semantics, and header guidelines.

## Permissions

- `copies_to_clipboard`
- `reads_launcher_input`

## Sample

Input: `429`  
Output cards:
- **MDN Spec:** `https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/429`
- **HTTP Cat:** `https://http.cat/429`
- **Markdown Link:** `[HTTP 429](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/429)`
