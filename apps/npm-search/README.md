# npm package search

Type `npm` and a package name in the Bolt launcher to search npmjs.com directly.

## Who it is for

JavaScript, TypeScript, and Node.js developers who frequently check npm packages, dependencies, and documentation.

## What it saves

Eliminates opening a browser, navigating to npmjs.com, and clicking into the search box.

## Permissions

- `opens_links:npmjs.com`

## Sample

- `npm react` -> Opens `https://www.npmjs.com/search?q=react`
- `npm @types/node` -> Opens `https://www.npmjs.com/search?q=%40types%2Fnode`
